# คู่มือการตั้งค่าเซนเซอร์และการสอบเทียบค่า

PEA PowerMeter (ESP32 + BL0942 + DS18B20) เฟิร์มแวร์ v3.0.103

## การเข้าหน้าตั้งค่า

1. เชื่อมต่อมือถือหรือคอมพิวเตอร์เข้ากับเครือข่าย Wi-Fi เดียวกับบอร์ด
2. เปิดเบราว์เซอร์แล้วพิมพ์ http://<IP ของบอร์ด>/settings หรือกดปุ่ม Settings ที่มุมขวาบนของหน้า Dashboard
3. หน้าตั้งค่าแบ่งเป็น 5 แท็บ ได้แก่ Sensors, Calibration, MQTT, Wi-Fi และ Firmware คู่มือฉบับนี้ครอบคลุม 2 แท็บแรก
4. ค่าทุกอย่างที่กด Save แล้วจะถูกเก็บในหน่วยความจำถาวรของบอร์ด ไฟดับหรือรีบูตแล้วค่ายังคงอยู่

หมายเหตุ: แท็บที่เปิดอยู่จะถูกจำไว้ในที่อยู่เว็บ (เช่น /settings#calibration) กด Refresh แล้วจะกลับมาที่แท็บเดิม

## ส่วนที่ 1 แท็บ Sensors การจัดช่องและตั้งชื่อหัววัดอุณหภูมิ

### 1.1 หลักการทำงาน

บอร์ดรองรับหัววัดอุณหภูมิ DS18B20 ได้สูงสุด 9 ตัวบนสายสัญญาณ 1-Wire เส้นเดียว หัววัดแต่ละตัวมีรหัสประจำตัว (ROM address) 64 บิตที่ไม่ซ้ำกันฝังมาจากโรงงาน บอร์ดใช้รหัสนี้ผูกหัววัดเข้ากับ "ช่อง" (Slot) หมายเลข 1 ถึง 9 ซึ่งเป็นตำแหน่งคงที่บน Dashboard และเป็นชื่อคีย์ temp1 ถึง temp9 ที่ส่งขึ้น ThingsBoard

เนื่องจากช่องผูกกับรหัส ROM ไม่ใช่ลำดับการเดินสาย ตำแหน่งของหัววัดจึงไม่สลับกันหลังรีบูต และหากหัววัดตัวใดหายไปจากสาย ช่องนั้นจะแสดงสถานะ offline โดยไม่ทำให้ช่องอื่นเลื่อน

หัววัด DS18B20 ไม่มีไฟแสดงตำแหน่ง วิธีเดียวที่จะรู้ว่าหัววัดตัวไหนคือแถวไหนบนหน้าจอ คือใช้นิ้วบีบหัววัดให้ร้อนขึ้นแล้วสังเกตว่าแถวใดอุณหภูมิเพิ่มขึ้น ค่าอุณหภูมิบนหน้าจอเป็นค่าสดที่อัปเดตทุกวินาที จึงทำได้จากหน้างานโดยไม่ต้องเดินกลับมาดูจอ

### 1.2 องค์ประกอบบนหน้าจอ

| องค์ประกอบ | คำอธิบาย |
|---|---|
| หมายเลขช่อง (1 ถึง 9) | ตำแหน่งคงที่ของหัววัดบน Dashboard และในข้อมูลที่ส่งขึ้นเซิร์ฟเวอร์ |
| อุณหภูมิสด | ค่าปัจจุบันของหัววัดในแถวนั้น สีของตัวเลขไล่จากน้ำเงิน (เย็น) ไปแดง (ร้อน) ตามช่วง 20 ถึง 50 องศาเซลเซียส เหมือนกับบน Dashboard |
| ช่องชื่อ | ชื่อที่ตั้งให้หัววัด พิมพ์ได้ไม่เกิน 15 ตัวอักษร ชื่อนี้จะแสดงบน Dashboard และส่งไป ThingsBoard เป็น attribute |
| รหัส ROM | รหัสประจำตัว 16 หลักของหัววัด ใช้ตรวจสอบตัวตนเมื่อเปลี่ยนหัววัด |
| ปุ่มลูกศรขึ้นลง | สลับลำดับช่อง ปุ่มจะจางลงเมื่อแถวอยู่บนสุดหรือล่างสุดแล้ว |
| สถานะ offline | แถวจะจางลงและแสดงคำว่า offline เมื่อหัววัดไม่ตอบสนองบนสาย ช่องและชื่อยังคงอยู่ |
| กล่อง On the bus, no slot free | แสดงเฉพาะเมื่อครบ 9 ช่องแล้วและมีหัววัดตัวใหม่ตอบสนองบนสาย ใช้สำหรับเปลี่ยนหัววัดที่เสีย (ดูข้อ 1.4) |
| ปุ่ม Rescan bus | สั่งให้บอร์ดค้นหาหัววัดบนสายใหม่ทั้งหมด ใช้เมื่อเสียบหัววัดเพิ่มหลังเปิดเครื่อง รอประมาณ 3 วินาที |
| ปุ่ม Save order & names | บันทึกลำดับช่องและชื่อทั้งหมดลงหน่วยความจำถาวร เมื่อสำเร็จจะมีข้อความ Saved ปรากฏด้านล่างจอ |

ข้อควรจำ: การพิมพ์ชื่อ การเลื่อนลำดับ และการกด Use เป็นเพียงการจัดบนหน้าจอ ค่าจะยังไม่ถูกบันทึกจนกว่าจะกด Save order & names

### 1.3 ขั้นตอนการตั้งค่าครั้งแรก

1. เปิดแท็บ Sensors ตรวจสอบว่าจำนวนแถวตรงกับจำนวนหัววัดที่ติดตั้งจริง หากไม่ครบ ให้ตรวจการเดินสายแล้วกด Rescan bus รอ 3 วินาที
2. ใช้นิ้วบีบหัววัดตัวแรกค้างไว้ 5 ถึง 10 วินาที สังเกตว่าแถวใดอุณหภูมิเพิ่มขึ้น
3. พิมพ์ชื่อตามตำแหน่งติดตั้งจริงลงในช่องชื่อของแถวนั้น เช่น Inlet water, Bearing DE, Ambient
4. ทำซ้ำข้อ 2 และ 3 จนครบทุกตัว
5. ใช้ปุ่มลูกศรจัดลำดับช่องให้ตรงกับที่ต้องการแสดงบน Dashboard
6. กด Save order & names รอจนมีข้อความ Saved ปรากฏ
7. กลับไปที่ Dashboard ตรวจสอบว่าชื่อและลำดับถูกต้อง

### 1.4 ขั้นตอนการเปลี่ยนหัววัดที่เสีย

เมื่อหัววัดตัวใดเสีย แถวของหัววัดนั้นจะแสดงสถานะ offline บอร์ดยังคงช่องหมายเลขและชื่อเดิมไว้ เพื่อให้หัววัดตัวใหม่เข้ามารับช่วงต่อได้โดยที่ Dashboard และข้อมูลบน ThingsBoard ไม่เปลี่ยนตำแหน่ง

1. ต่อหัววัดตัวใหม่เข้ากับสาย 1-Wire ไม่จำเป็นต้องถอดหัววัดที่เสียออกก่อน
2. เปิดแท็บ Sensors แล้วกด Rescan bus รอ 3 วินาที
3. หัววัดตัวใหม่จะปรากฏในกล่อง On the bus, no slot free พร้อมค่าอุณหภูมิสด (หากยังไม่ครบ 9 ช่อง หัววัดใหม่จะถูกเพิ่มเป็นช่องใหม่ต่อท้ายแทน ให้ตั้งชื่อและ Save ตามข้อ 1.3 ได้เลย)
4. บีบหัววัดตัวใหม่เพื่อยืนยันว่าอุณหภูมิในกล่องนั้นเพิ่มขึ้น
5. ในช่องเลือกด้านขวาของหัววัดใหม่ ระบบจะเลือกช่องที่ offline ให้โดยอัตโนมัติ (เช่น Slot 4 Ambient (offline)) ตรวจสอบว่าเป็นช่องของหัววัดที่เสียจริง
6. กด Use หัววัดใหม่จะเข้าไปแทนที่ช่องนั้นโดยใช้ชื่อเดิม และจะมีข้อความเตือนให้กด Save
7. กด Save order & names รอจนมีข้อความ Saved ปรากฏ ช่องนั้นจะกลับมาแสดงค่าอุณหภูมิตามปกติ
8. ถอดหัววัดที่เสียออกจากสายได้เมื่อสะดวก

ข้อควรระวัง: หากเลือกช่องที่ยัง online อยู่แล้วกด Use ระบบจะถามยืนยันก่อน เพราะเป็นการนำหัววัดที่ยังใช้งานได้ออกจาก Dashboard หัววัดที่ถูกแทนที่จะย้ายลงมาอยู่ในกล่อง On the bus, no slot free แทน

### 1.5 การแก้ปัญหา

| อาการ | สาเหตุที่พบบ่อย | วิธีแก้ |
|---|---|---|
| ขึ้นข้อความ no DS18B20 found on the bus | ไม่มีตัวต้านทาน pull-up 4.7 กิโลโอห์ม หรือสายสัญญาณหลุด | ตรวจตัวต้านทานระหว่างสายข้อมูลกับ 3.3V ตรวจการเดินสาย แล้วกด Rescan bus |
| หัววัดใหม่ไม่ปรากฏหลัง Rescan | สายไม่แน่น หรือหัววัดเกิน 16 ตัวบนสาย | ตรวจจุดต่อ ลดจำนวนหัววัด แล้ว Rescan อีกครั้ง |
| แถวแสดง offline ทั้งที่หัววัดยังดี | สายยาวเกินไปหรือสัญญาณรบกวน | ตรวจสายและจุดต่อ ลองใช้ตัวต้านทาน pull-up ค่าต่ำลง |
| อุณหภูมิไม่ขึ้นเมื่อบีบ | บีบไม่นานพอ หรือหัววัดอยู่ในน้ำหรือโลหะที่ระบายความร้อนเร็ว | บีบค้างอย่างน้อย 10 วินาที หรือใช้ลมร้อนเป่าเบาๆ |
| กด Save แล้วขึ้น Failed | ชื่อยาวเกิน 15 ตัวอักษร หรือการเชื่อมต่อขาดหาย | ย่อชื่อ ตรวจ Wi-Fi แล้วกด Save อีกครั้ง |

## ส่วนที่ 2 แท็บ Calibration การสอบเทียบค่าไฟฟ้า

### 2.1 หลักการทำงาน

ชิปวัดพลังงาน BL0942 ให้ค่าแรงดัน กระแส และกำลังไฟจากค่าคงที่ของโรงงาน ซึ่งเป็นเพียงจุดเริ่มต้นและอาจคลาดเคลื่อนจากค่าจริงเล็กน้อยตามความต้านทานของวงจรแบ่งแรงดันและตัวต้านทานวัดกระแสในแต่ละบอร์ด การสอบเทียบคือการกำหนดตัวคูณ 3 ค่า ได้แก่

- kV ตัวคูณแรงดัน (Volt)
- kI ตัวคูณกระแส (Ampere)
- kP ตัวคูณกำลังไฟ (Watt)

ค่าที่แสดง = ค่าดิบจากชิป x ค่าคงที่โรงงาน x ตัวคูณ

ค่าเริ่มต้นของตัวคูณทั้งสามคือ 1.0000 ตัวคูณ kP มีผลต่อการสะสมหน่วยไฟฟ้า (kWh) ด้วย เนื่องจากพลังงานคำนวณจากกำลังไฟ ค่าที่ปรับใหม่จะมีผลกับการสะสมนับจากเวลาที่กด Save เป็นต้นไป ไม่ย้อนแก้ค่าที่สะสมไปแล้ว

### 2.2 องค์ประกอบบนหน้าจอ

| องค์ประกอบ | คำอธิบาย |
|---|---|
| Live reading | ค่าแรงดัน (Volts) กระแส (Amps) และกำลังไฟ (Watts) ปัจจุบัน เป็นค่าที่ผ่านตัวคูณแล้ว อัปเดตทุกวินาที ใช้เทียบกับมิเตอร์อ้างอิงและดูผลทันทีหลัง Save |
| Current kI | ช่องกรอกตัวคูณกระแส ทศนิยม 4 ตำแหน่ง ต้องมากกว่า 0 |
| Voltage kV | ช่องกรอกตัวคูณแรงดัน |
| Power kP | ช่องกรอกตัวคูณกำลังไฟ |
| ปุ่ม Save | บันทึกตัวคูณทั้งสามลงหน่วยความจำถาวรทันที เมื่อสำเร็จจะขึ้นข้อความ Calibration saved หากค่าใดไม่ใช่ตัวเลขหรือไม่มากกว่า 0 จะขึ้นข้อความ Each factor must be a number above 0 และไม่บันทึก |
| Accumulated energy | หน่วยไฟฟ้าสะสม (kWh) นับตั้งแต่รีเซ็ตครั้งล่าสุด บอร์ดบันทึกค่านี้ลงหน่วยความจำทุก 1 นาที หากไฟดับจะเสียค่าไม่เกิน 1 นาทีล่าสุด |
| ปุ่ม Reset counter | ล้างหน่วยไฟฟ้าสะสมเป็น 0 มีกล่องยืนยันก่อน การรีเซ็ตย้อนกลับไม่ได้ |

### 2.3 อุปกรณ์ที่ต้องใช้

- โหลดไฟฟ้าที่กินกำลังคงที่ เช่น ฮีตเตอร์หรือหลอดไส้ ขนาด 200 ถึง 500 วัตต์ (หลีกเลี่ยงโหลดที่กำลังไฟแกว่ง เช่น มอเตอร์ สวิตชิ่ง หรือหลอด LED)
- มิเตอร์อ้างอิงที่ผ่านการสอบเทียบแล้ว ชนิด True RMS เช่น power analyzer หรือมัลติมิเตอร์ร่วมกับคลิปแอมป์ True RMS
- มิเตอร์อ้างอิงต้องวัดที่จุดเดียวกับที่บอร์ดวัด

### 2.4 ขั้นตอนการสอบเทียบ

1. ต่อโหลดคงที่และมิเตอร์อ้างอิงเข้ากับวงจรที่บอร์ดวัดอยู่ เปิดโหลดแล้วรอให้ค่านิ่งอย่างน้อย 30 วินาที
2. เปิดแท็บ Calibration จดค่า Volts, Amps, Watts จาก Live reading และจดค่าจากมิเตอร์อ้างอิงในเวลาเดียวกัน
3. จดค่าตัวคูณปัจจุบันในช่อง kV, kI, kP
4. คำนวณตัวคูณใหม่ทีละค่าด้วยสูตร

   ตัวคูณใหม่ = ตัวคูณปัจจุบัน x (ค่าจากมิเตอร์อ้างอิง / ค่าที่บอร์ดแสดง)

   (ข้อความแนะนำบนหน้าจอเขียนว่า kV = true_volts / displayed_volts ซึ่งใช้ได้เมื่อตัวคูณปัจจุบันเป็น 1.0000 เท่านั้น หากเคยสอบเทียบมาแล้วให้ใช้สูตรข้างต้น)
5. พิมพ์ตัวคูณใหม่ลงในช่อง kV, kI, kP ปัดทศนิยม 4 ตำแหน่ง แล้วกด Save รอข้อความ Calibration saved
6. ดู Live reading อีกครั้ง ค่าควรตรงกับมิเตอร์อ้างอิงภายในเกณฑ์ที่ยอมรับ (แนะนำไม่เกิน 0.5 เปอร์เซ็นต์) หากยังต่างให้ทำซ้ำข้อ 2 ถึง 5 อีกหนึ่งรอบ
7. บันทึกหมายเลขเครื่อง วันที่ ค่า kV kI kP สุดท้าย และหมายเลขมิเตอร์อ้างอิง ลงในบันทึกสอบเทียบ

### 2.5 ตัวอย่างการคำนวณ

| ค่าที่วัด | บอร์ดแสดง | มิเตอร์อ้างอิง | ตัวคูณปัจจุบัน | ตัวคูณใหม่ |
|---|---|---|---|---|
| แรงดัน (V) | 229.8 | 230.5 | 1.0000 | 1.0030 |
| กระแส (A) | 1.245 | 1.251 | 1.0000 | 1.0048 |
| กำลังไฟ (W) | 283.6 | 286.0 | 1.0000 | 1.0085 |

ตัวอย่าง kV ใหม่ = 1.0000 x (230.5 / 229.8) = 1.0030

หมายเหตุ: ตัวคูณ kP ปรับแยกจาก kV และ kI ได้ เพราะชิปคำนวณกำลังไฟจากรีจิสเตอร์ของตัวเอง ไม่ได้นำ V คูณ A ในเฟิร์มแวร์

### 2.6 การรีเซ็ตหน่วยไฟฟ้าสะสม

1. จดค่า Accumulated energy ปัจจุบันลงบันทึกก่อนเสมอ
2. กด Reset counter แล้วกดยืนยันในกล่องที่ปรากฏ
3. ค่าจะกลับเป็น 0.000 kWh และขึ้นข้อความ Energy counter reset

ข้อควรระวัง: ห้ามรีเซ็ตหน่วยไฟฟ้าสะสมในเครื่องที่ใช้ค่า kWh สำหรับคิดค่าไฟหรือรายงาน โดยไม่ได้จดค่าเดิมและได้รับอนุมัติจากผู้รับผิดชอบก่อน การรีเซ็ตย้อนกลับไม่ได้

## อภิธานศัพท์

| คำศัพท์ | ความหมาย |
|---|---|
| Slot (ช่อง) | ตำแหน่งคงที่หมายเลข 1 ถึง 9 บน Dashboard ที่ผูกกับหัววัดหนึ่งตัวผ่านรหัส ROM |
| ROM address | รหัสประจำตัว 64 บิต (16 หลักฐานสิบหก) ที่ฝังในหัววัด DS18B20 แต่ละตัวจากโรงงาน ไม่ซ้ำกัน |
| Bus (สาย 1-Wire) | สายสัญญาณเส้นเดียวที่หัววัดทุกตัวต่อขนานกัน ต้องมีตัวต้านทาน pull-up 4.7 กิโลโอห์ม |
| Rescan | การสั่งให้บอร์ดค้นหาหัววัดบนสายใหม่ทั้งหมดโดยไม่ต้องรีบูต |
| Offline | หัววัดที่อยู่ในรายการที่บันทึกไว้แต่ไม่ตอบสนองในการค้นหาครั้งล่าสุด |
| Spare | หัววัดที่ตอบสนองบนสายแต่ไม่มีช่องว่างให้ จึงยังไม่ถูกอ่านค่าหรือส่งข้อมูล |
| kV, kI, kP | ตัวคูณสอบเทียบแรงดัน กระแส และกำลังไฟ ที่คูณทับค่าคงที่โรงงานของชิป |
| True RMS | วิธีวัดค่าประสิทธิผลที่ถูกต้องแม้รูปคลื่นไม่เป็นไซน์ มิเตอร์อ้างอิงควรเป็นชนิดนี้ |
| Accumulated energy | ผลรวมพลังงานไฟฟ้า (kWh) ตั้งแต่รีเซ็ตครั้งล่าสุด |
| Toast | ข้อความแจ้งผลสั้นๆ ที่ปรากฏด้านล่างจอแล้วหายไปเอง เช่น Saved |
